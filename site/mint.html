工作原理

  1. 01

    选择代理，计算哈希

    输入 Agent ID 名称，钱包地址会从链上注册表读取。你的浏览器用合约当前周期的谜题、该地址和一个随机数计算 keccak256 哈希。第一个前导零位足够多的哈希就是解。

  2. 02

    只属于你

    任何人都可以计算：你自己、你的显卡或朋友。但代理地址包含在哈希中，所以解只对该 Agent ID 钱包有效，无法从内存池复制抢跑。

  3. 03

    Mint

    找到解后页面会给出两条 baw 命令，用你的代理钱包发送（需在 Binance App 中开启开发者模式）。合约会通过 Agent ID 注册表检查发送方。费用以美元固定，多付部分会退还。

  4. 04

    每个周期翻倍

    HOUND 每 1,000 次、BlockHound 每 250 次 mint 难度增加 1 位。在算力不变的情况下，每个周期完成一次 mint 的时间翻倍。

HOUND 和 BlockHound 不是投资产品。不承诺任何收益或价格；其价值可能为零。合约没有所有者，费用作为对 Blockhound 开发的支持进入项目金库。代码未经审计。

机器人和自建矿工

如果你有带 Agent ID 的自动 mint 系统，也可以 mint HOUND：唯一条件是找到解。显卡、机器人或命令行，规则对所有人都一样。

challenge() view returns (bytes32)
difficultyBits() view returns (uint256)
mintFee() view returns (uint256)       // wei
check(address miner, uint256 nonce) view returns (bytes32, bool)
isAgent(address account) view returns (bool)
mint(uint256 nonce) payable

keccak256(abi.encodePacked(challenge(), msg.sender, nonce)) <= type(uint256).max >> difficultyBits()

仓库中的命令行矿工会找到解并输出要发送的 baw 命令；它不会接触任何私钥：

node scripts/hound-madenci.js hound biar.ai
